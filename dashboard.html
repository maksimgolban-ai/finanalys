Логика страницы

Главный дэшборд агрегирует клиентские данные листов Деньги, Прибыль и Капитал без Apps Script.

Сводная аналитика

Финансовый дашборд

Единый клиентский слой расчета показателей на основе данных из трех финансовых листов.

YTD-агрегация по snapshotDate

Сводная страница для ликвидности, прибыли и капитала

Страница автоматически ищет последнюю доступную дату на листе Капитал, привязывает к ней расчеты и пересчитывает показатели Деньги и Прибыль в режиме с 1 января года snapshotDate по snapshotDate.

Период пользователя

Выбор даты для привязки к срезу капитала

Snapshot date — Последняя дата листа Капитал, которая не позже выбранной даты окончания периода.
Период пользователя — Фильтр в шапке управляет поиском актуального среза капитала.
Фактический расчетный период — Для денег и прибыли всегда используется годовой период от 1 января до snapshotDate.

Источники данных для главного дэшборда не найдены

Страница ожидает клиентские данные листов Деньги, Прибыль и Капитал.

  • Поддерживается window.workbookData, если внутри есть листы с ожидаемыми названиями.
  • Поддерживаются отдельные переменные window.rangecash, window.rangeprofit, window.rangeequity.
  • Также поддерживаются window.cashData, window.profitData, window.capitalData.

      Чистый денежный поток по месяцам

      Динамика дебиторской задолженности

      Отражаются только отчетные даты, которые фактически присутствуют в данных листа Капитал.

      Динамика кредиторской задолженности

      Серия строится по значениям Раздел 3 = Кредиторская задолженность на отчетные даты.

      Заемный и собственный капитал

      Диаграмма накопления показывает структуру Капитал + Обязательства = 100%.

      Коэффициент финансовой независимости

      Рассчитывается как Капитал / Активы на каждую доступную отчетную дату листа Капитал.
