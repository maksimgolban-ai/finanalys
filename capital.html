Источник модуля

Раздел рассчитывается в браузере и ожидает клиентские данные листа Капитал в диапазоне rangeequity.

Раздел системы

Капитал

Балансовые срезы, структура активов и пассивов, долговая динамика и коэффициенты устойчивости на клиентской стороне.

Модуль баланса

Структура активов и пассивов, долговая нагрузка и коэффициенты устойчивости

Страница работает полностью в браузере: ожидает клиентский набор rangeequity, проверяет обязательные колонки, фильтрует отчетные даты и строит KPI по последнему доступному срезу внутри выбранного периода.

Источник не подключен
Период страницы — Балансовые срезы строятся только по отчетным датам внутри периода.
Строк после фильтрации 0 Считаются только строки с валидной датой и обязательными колонками.
Последний срез — Для карточек и структурных диаграмм используется последняя дата ≤ границе периода.
Покрытие дат — Покрытие всех отчетных дат из клиентского источника.
Управление выборкой

Период анализа

Других фильтров нет. Если точной даты среза на конец периода нет, система берет последнюю доступную дату, которая не превышает выбранную границу.

Период не задан
Фильтр по периоду ещё не применён.

Источник данных для раздела “Капитал” пока не найден

Модуль ожидает browser-side данные листа Капитал. Здесь не используется Apps Script и нет серверной логики.

  • Поддерживается window.capitalData как массив объектов или строк диапазона.
  • Поддерживается window.rangeequity с тем же принципом.
  • Поддерживается window.workbookData, если лист Капитал доступен в клиентском runtime.

    100% = Капитал + Обязательства. График строится только по реальным отчетным датам, а доли доступны во всплывающей подсказке.
