Источник модуля

Раздел рассчитывается в браузере и ожидает клиентские данные листа Прибыль в диапазоне rangeprofit.

Раздел системы

Прибыль

Выручка, валовая прибыль, чистая прибыль и рентабельность по данным ОПиУ на клиентской стороне.

Модуль ОПиУ

Прибыль по периодам, направлениям и проектам без серверной прослойки

Страница работает полностью в браузере: ожидает клиентский набор rangeprofit, нормализует даты и знак суммы, фильтрует период и признаки, затем пересчитывает KPI, графики и проектные таблицы.

Источник не подключен
Период по умолчанию — По умолчанию используется текущий календарный месяц.
Строк после фильтрации 0 Учитываются только строки с валидной датой в колонке Дата.
Покрытие дат — Диапазон исходных дат после клиентской нормализации.
Активные фильтры 0 Проект, направление, статья и раздел ОПиУ работают совместно.

Источник данных для раздела “Прибыль” пока не найден

Модуль ожидает browser-side данные листа Прибыль. Здесь не используется Apps Script и нет серверной логики.

  • Поддерживается window.profitData как массив объектов или строк диапазона.
  • Поддерживается window.rangeprofit с тем же принципом.
  • Поддерживается window.workbookData, если лист Прибыль доступен в клиентском runtime.
