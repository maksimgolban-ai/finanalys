# Финансовый дашборд

Статический multi-page дашборд для разделов:

- `dashboard.html`
- `money.html`
- `profit.html`
- `capital.html`

## Что уже готово

- Проект можно публиковать как обычный статический сайт.
- Главная точка входа для GitHub Pages: `index.html`.
- Автодеплой в GitHub Pages настроен через `.github/workflows/deploy-pages.yml`.
- Excel-файл подгружается в браузере по публичной ссылке Яндекс.Диска, затем парсится локально через `SheetJS`.

## Как разместить на GitHub

1. Создайте репозиторий на GitHub.
2. Загрузите в него содержимое этой папки.
3. Убедитесь, что основная ветка называется `main`.
4. В настройках репозитория откройте `Settings` → `Pages`.
5. В разделе `Build and deployment` выберите `Source: GitHub Actions`.
6. Сделайте push в ветку `main`.
7. Дождитесь выполнения workflow `Deploy GitHub Pages` во вкладке `Actions`.

После публикации сайт будет доступен по адресу вида:

- `https://USERNAME.github.io/REPOSITORY/`

## Важно

- Поле источника данных сохраняется в `localStorage`, поэтому новый URL Excel-файла можно задать прямо в интерфейсе.
- Для загрузки Excel публичная ссылка Яндекс.Диска должна оставаться доступной.
- Если GitHub Pages уже был настроен на публикацию из ветки, переключите источник на `GitHub Actions`.
